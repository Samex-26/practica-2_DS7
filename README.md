# Práctica 2 - Desarrollo de Software 7

Este repositorio contiene ejercicios prácticos de la asignatura Desarrollo de Software 7, implementados en PHP. Su objetivo es reforzar conceptos básicos de programación y organización de proyectos en un entorno real de control de versiones con GitHub.

## Contenido del repositorio
- prac1.php: Primer ejercicio práctico en PHP.
- prac2.php: Segundo ejercicio práctico en PHP.
- carpeta3/: Carpeta con archivos adicionales relacionados con la práctica.

## Requisitos
- PHP 7.4 o superior instalado en el sistema.
- Navegador web para visualizar resultados.
- Opcional: servidor local como XAMPP, Laragon o PHP built-in server.

## Objetivo
El propósito de estas prácticas es:
- Familiarizarse con la sintaxis de PHP.
- Aplicar conceptos de programación estructurada y modular.
- Practicar el uso de GitHub para gestionar proyectos de software.
